# LAB04 - Sistema de Gerenciamento de Biblioteca

Esta é uma aplicação desenvolvida em TypeScript para simular um sistema básico de gerenciamento de biblioteca, permitindo o cadastro de livros, registro de empréstimos e consulta de disponibilidade.

## Requisitos Técnicos Aplicados
- Uso de classes (`Livro` e `Biblioteca`).
- Encapsulamento com modificadores de acesso (`public` nas propriedades do livro, `private` no acervo da biblioteca).
- Tipagem estática explícita em variáveis, parâmetros e retornos de funções.
- Tratamento de erros para situações inválidas (livros inexistentes ou já emprestados).

## Como executar o programa

1. Certifique-se de ter o [Node.js](https://nodejs.org/) instalado em sua máquina.
2. Abra o terminal na pasta raiz do projeto (`LAB04`).
